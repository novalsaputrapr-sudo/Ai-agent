# Storyboard & Visual Production Guide

**Aspect Ratio:** 9:16 (Vertical Video - 1080x1920)  
**Target Platform:** YouTube Shorts / TikTok / Reels  
**Total Runtime:** ~45 seconds  

---

## Scene Breakdown

### Scene 1: The Hook (00:00 - 00:06)
* **Visual:** Close-up fast cut of an overheated, blinking GPU mining rig with a red 'X' overlay, transitioning quickly to an old laptop or dust-covered electronics drawer.
* **Text Overlay:** "Mining without expensive GPUs?" (Bold, centered, yellow/white text).
* **Audio Cue:** Fast whoosh sound effect into rhythmic tech-beat.

### Scene 2: The Core Mechanism (00:06 - 00:18)
* **Visual:** Minimal 2D schematic showing traditional Proof-of-Work energy consumption graph spiking red, dropping down to a green baseline labelled "Proof of Antiquity".
* **Text Overlay:** "Consensus: Proof of Antiquity"
* **Animation:** RustChain logo / gear icon turning smoothly.

### Scene 3: Hardware Diversity (00:18 - 00:30)
* **Visual:** Split-screen or 3-part vertical montage showing: (1) Raspberry Pi running terminal logs, (2) older x86 netbook with active CLI, (3) lightweight embedded hardware.
* **Text Overlay:** "Low Power. Real Nodes. Zero Waste."
* **B-Roll Reference:** Terminal output displaying node synchronization and epoch status.

### Scene 4: Rust Language & Safety (00:30 - 00:40)
* **Visual:** Code snippet highlight showcasing Rust memory-safe syntax (`async fn validate_node`, `match`, immutable references) on a dark IDE theme.
* **Text Overlay:** "Built in Rust: Lightweight & Memory-Safe"
* **Motion:** Code scrolling upward with smooth depth-of-field blur on top and bottom edges.

### Scene 5: Outro & Call to Action (00:40 - 00:45)
* **Visual:** Clean endcard displaying the RustChain repository badge, GitHub link, and RTC network marker.
* **Text Overlay:** "Verify the Code. Run a Node. rustchain/rustchain"
* **Audio Cue:** Quick digital chime fade-out.
